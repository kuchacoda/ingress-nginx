# Сборка релизных образов

Для обновления из Chainguard, сборки и публикации контейнеров используйте [инструкцию по релизам](docs/developer-guide/release-images.md) и `./build/release-images.sh`. Команда `latest` показывает опубликованный релиз upstream, а `plan` — исходный коммит, платформу и все три тега в плане Buildx. Обычный локальный скрипт и файлы `TAG` используют собственные версии компонентов.

Собирайте из принятого PR синхронизации. Выполняйте `publish`, когда пользователь просит опубликовать образы. В результате укажите полный адрес и digest каждого образа.
